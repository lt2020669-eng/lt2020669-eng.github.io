これは**サンプル**です。`draft: true` の記事はローカルの `npm run dev` でしか見えず、`npm run build` では自動的に除外されるため、公開サイトには出ません。

日記を書き始めるときは、このファイルをコピーするか、次のコマンドを実行してください。

```bash
npm run new -- diary ja "今日のタイトル"
```

本文は Markdown で書きます。

- リストはこう
- **太字**、*斜体*、[リンク](https://example.com)

> 引用はこう表示されます。

書き終えたら `draft` を `false` に変え、`git push` すれば、数分後には公開されます。
