**用到的东西：** Netlify、Google AI Studio、Cloudflare、Spaceship · [看这个站](https://8998800.xyz)

做完 Review 那个项目之后，我心里留下了几个特别想弄明白的问题。其中一个是：怎么用 AI 生成真正像母语者的语音——这个先卖个关子，以后再写。现在我想说的是我的新项目：Questionnaire。

另一个问题是关于域名的。我很好奇为什么 Review 用的域名是免费的，它和付费域名到底差在哪儿。后来我明白了，付费域名会让一个站看起来专业得多，于是我决定买一个自己的。

我做东西一直守着一条原则：**只做能解决我自己问题的东西**。所以这次我决定做一个问卷网站。做的过程中我发现 Cloudflare 也提供托管，于是顺便学会了怎么把新买的域名接到它上面。

## 我踩到的坑

我想做一个「导出 PDF」的功能，结果是一场灾难——内容会从页面中间被硬生生截断，出来的东西丑得不行。

现在页面底部还留着一个下载按钮。但说实话，如果你用的是 Chrome，直接按 Ctrl+P，得到的结果完全一样。

因为我当时还在用 Google AI Studio，而它生成的代码（大部分是 .ts 和 .json 文件）我根本看不懂，所以修不动。（这反而勾起了新的好奇：这是什么语言？它跟我新人培训时学的 Java 和 HTML 有什么区别？——正是这个问题，成了我下一个项目的引子。）最后我干脆放弃自己实现，就靠浏览器自带的打印功能来存 PDF。

## 顺着线往下摸

做完这个项目，我对 AI 的兴趣反而更旺了。我意识到，Google AI Studio 很适合做小型静态网站或者轻量后端，但更大、更复杂的开发有没有对应的工具？

查了一圈，我很快发现了 Cursor 和 Trae 这类厉害的工具。同时我对 GitHub 的看法也彻底变了。以前我只把 GitHub 当成一个复杂的源码仓库，完全没兴趣去搞懂它。但它在我查资料的过程中一次又一次地出现，我才意识到它有多重要，现在非常想好好摸一遍。这个项目就到这里！
